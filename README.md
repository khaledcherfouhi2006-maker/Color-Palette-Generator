# 🎨 Color Palette Generator

A modern, responsive web application designed to generate random five-color palettes with instant HEX code copying using vanilla **HTML5**, **CSS3**, and **JavaScript**.

🔗 **Live Demo:** [khaledcherfouhi2006-maker.github.io/Color-Palette-Generator](https://khaledcherfouhi2006-maker.github.io/Color-Palette-Generator/)

---

## ✨ Features

- **Random Palette Generation:** Dynamically produces 5 random harmonic HEX color codes at the click of a button.
- **One-Click HEX Copy:** Click directly on the color swatch or the copy icon to copy the HEX value to your clipboard via the modern Clipboard API.
- **Visual Feedback:** Instant confirmation indicator (check icon with color feedback) when a code is successfully copied.
- **Modern UI & Animations:** Clean glassmorphism-inspired layout, gradient styling, card elevation, and smooth hover interactions.
- **Responsive Layout:** Adaptive CSS Grid that automatically adjusts from desktop cards down to mobile screen sizes.

---

## 🛠️ Built With

- **HTML5:** Semantic card containers, control buttons, and Font Awesome icon integration.
- **CSS3:** CSS Grid, Flexbox, linear gradients, transitions, and responsive media queries.
- **JavaScript (ES6):** Random hex algorithm, DOM traversal, event delegation, and asynchronous Clipboard API (`navigator.clipboard`).
- **GitHub Pages:** Static site hosting and deployment.
